## Problem Description :- 
*The objective of this assignment is to create a JavaScript program that calculates compound interest based on static values.*
## Tasks:
* Write a JavaScript program that calculates compound interest.
* Use variables and operators.
* Formula for Compound Interest:
* The formula to calculate compound interest is as follows:
    * ```A = P * (1 + (r / n)) ^ n * t```  
* Where:  
    ``` 
    A = amount
    P = principal
    r = rate of interest
    n = number of times interest is compounded per year
    t = time (in years)
     ```
