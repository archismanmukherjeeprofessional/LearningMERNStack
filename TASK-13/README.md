# TASK 13 : Even and Odd Checker: Using JS

### **By this task I learned and strenghten the concept on if else statements of JS**
## Problem Description :- 
*The objective of this assignment is to create a JavaScript program that checks whether a given number is even or odd.*
## Tasks:
* Write a JavaScript program that checks if a given number is even or odd.
* Use Three four different variables.
* Console.log a message indicating whether the number is even or odd.
* Use an if-else statement to determine if the number is even or odd.

* Click on the given deployed link or download the provided **.zip file** and extract it and open the extracted folder and **double click** on the **index.html** file.

* To view the code **right click** on the **index.html** file and open with any text editor.
* For **JS** Open **Dev tools** and Go to **Console** Page.
