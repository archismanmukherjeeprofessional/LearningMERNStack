# TASK 8 : CSS - Laundry Services | Hamburger menu with pure CSS

### **By this task I learned and strenghten by concept on CSS Pseudo Selectors(especially :focus).**
## Problem Statement: 
*Develop a Hamburger Menu For the mobile view of the Laundry Web App.*
## Problem Description: 
*While making our website responsive in the last
assignment we removed the links from the mobile version. Now we have to make a hamburger menu icon when the user clicks, it should open a menu from the right side of the screen.*
## Tasks:
### Navbar:
* Add a hamburger menu Icon in the navbar and by default keep it hidden.
* Make its visibility on for mobile view only.
### Menu List:
* Make a div and keep its position absolute on the right side of the screen.
* Keep its display none by default.
### Showing List on Click:
* As of now we won't use any javascript to track the click we will just wrap the hamburger icon in a button and use **:focus** pseudo class to track if the button is in focus then display the list.
## **How to Run:**
* Click on the given deployed link or download the provided **.zip file** and extract it and open the extracted folder and **double click** on the **index.html** file.

* To view the code **right click** on the **index.html** file and open with any text editor.
